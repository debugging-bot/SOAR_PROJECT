# 수형 그림 (국립국어원 한국수어사전)

`labels.json`의 10개 단어에 해당하는 한국수어사전의 **수형 사진(선 그림)**을 원본 그대로 저장한 폴더입니다.
확정 화면의 동작 그림과 그림 퀵 키워드 버튼(10주차 중간발표 피드백 7)에 씁니다.

- 출처: 국립국어원 한국수어사전 <https://sldict.korean.go.kr>
- 받은 날: 2026-11-02
- 목록과 상세 정보: [`signs.json`](signs.json) (항목 번호, 표제어, 수형 설명, 원본 주소)

## 이용 조건 (반드시 지킬 것)

한국수어사전 자료는 **크리에이티브 커먼즈 저작자표시-비영리-변경금지 2.0 대한민국(CC BY-NC-ND 2.0 KR)** 라이선스입니다.

| 조건 | 우리가 할 일 |
|---|---|
| 저작자 표시 | 그림이 나오는 화면·발표 자료·보고서에 "출처: 국립국어원 한국수어사전" 표기 |
| 비영리 | 캡스톤 과제·부스 시연은 해당. 상업적 사용 불가 |
| 변경 금지 | 그림을 자르거나 색·글씨를 덧입히거나 합성하지 않음. 화면에서 크기만 조절해 그대로 표시 |
